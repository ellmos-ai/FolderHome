# FolderHome Skills

**English** | [Deutsch](./README.de.md)

New, agentically controllable skill packages are being created here. The planned family includes, among others, document maintenance, folder reports, topic dossiers, FindCall, as well as administrative household, health, and financial processes.

The Phase-18 FindCall service already provides the encapsulated core for a later agentic skill, but remains, in the competitive context, a strictly local fixture simulation without telephone or network access.

The Phase-21 medication service also provides a reusable, evidence‑bound core for supplied schedules, daily views, and explicitly confirmed intakes. It is deliberately not a diagnosis, prescription, dosage, or reminder agent.

The Phase-22 health dossier core aggregates local documents extractively and evidence‑bound. It shows direct conflicts, source distances, and error status, but intentionally remains without diagnosis, therapy decision, remote LLM, or completeness guarantee.

The Phase-23 contract cockpit core combines existing document, contact, cost, appointment, and coverage views via an explicit join contract. It is a read‑only orchestration and performs neither archiving nor communication, calendar, or financial actions.

The Phase-24 correspondence core encapsulates controlled templates, explicit design inheritance, and deterministic Markdown/TXT output. It can later be used by agentic letter or government workflows, without silently providing shipping, legal decision, or Office rendering.

The Phase-25 skill `folderhome-artifact-studio` routes presentations, tables, documents, and media to existing specialists and respects their own runtime and visibility checks. FolderHome itself generates only the new encapsulated design‑set/SVG core; blocked providers are neither replaced nor emitted as finished.

The Phase-26 skill `folderhome-mail-assistant` separates read‑only mailbox retrieval, local attachment output, mailbox mutations, and sending. It requires an explicit contact/correspondence binding and a one‑time sending ledger; the approved gateway is purely synthetic and does not send any email.

The Phase-27 skill `folderhome-calendar-connectors` builds exclusively on the existing calendar handoff. It distinguishes UpToday‑ICS, Routinika‑Bundle, Google skill, and a synthetic no‑network provider, requires exact calendar and operation bindings, and does not claim any live calendar entry.

The Phase-28 skill `folderhome-personal-notes` guides people through separate questions and suggestions via personal notes. Only the exactly confirmed content is appended‑only in the pinned `llm-note` store; remote LLM, external synchronization, overwriting, and deletion remain excluded.

The Phase-29 skill `folderhome-tax-workpaper` exclusively handles human‑sorted, catalog‑bound evidence in the pinned local tax agent. It generates private working documents after its own approval, but no tax advice, official declaration, or portal transmission.

The Phase-30 skill `folderhome-daily-briefing` aggregates local weather and news snapshots into a source‑aware HTML letter. Rendering and desktop copy remain separately approved; live network and scheduler are not silently simulated.

The Phase-31 skill `folderhome-official-notices` explicitly records labeled official notice data with line and hash evidence. Relative deadline wordings are not converted into statutory dates; legal review, response, and external effect remain excluded.

The Phase-32 skill `folderhome-administrative-drafts` links this evidence with the existing correspondence studio. Objection, response, and application drafts remain visibly unchecked, require a separate content approval, and have no sending path.

The Phase-33 skill `folderhome-benefit-screening` loosely maps a few local user entries to official pre‑checks. It blocks outdated sources, flags catalog gaps, and claims neither entitlement nor amount, completeness, or application.

The Phase-34 skill `folderhome-legal-change-monitor` compares dated, hash‑bound legal source snapshots and assigns changes exclusively to explicitly recorded topics as review candidates. Drafts, promulgation, legal effect, affected parties, deadlines, and notifications remain separate.

The Phase-36 skill `folderhome-strands-agent` provides the mandatory Strands‑Agents‑Loop. It routes exclusively to profile‑bound read‑only document search and topic dossiers, limits turns, tools, and results, and separates the reproducible no‑network fixture run from an explicitly approved Bedrock run.
