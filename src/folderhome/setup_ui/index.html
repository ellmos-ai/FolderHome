Set up FolderHome

This program is the only place that writes FolderHome configuration. The app itself never changes it. Nothing is written before you confirm the exact plan.

1. Folders

Give each profile a folder per purpose. Source folders are read, output folders receive files. Leave a field empty to skip that purpose.

2. Model

The provider is a start-up choice. Network and data approvals stay command-line flags and are never written to a file.

3. Runtime

4. Summary and save

Saving replaces resources.json completely. Entries you added by hand are lost; the previous version stays next to it as .bak-<timestamp>.

Nothing is saved automatically. Check first, then save; saving writes resources.json and launch.json.

Cloud variant

In the AWS or browser variant there are no local output folders. There the results view is the delivery path: files are downloaded into the browser's own download folder.
