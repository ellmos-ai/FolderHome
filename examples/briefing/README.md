# Synthetic Weather and Newspaper Brief

**English** | [Deutsch](./README.de.md)

All locations, messages, and sources under this folder are test data.  
The domains containing `.invalid` cannot be inadvertently accessed as real sources.

`briefing-request.json` refers relatively to a weather and a news snapshot.  
The plan reads them only after sensitivity approval and does not make any network calls. Rendering and copying into an explicitly chosen desktop folder require two separate approvals.

The example data state is intentionally tied to the fixed acceptance date  
2026-08-22. For any other day, the date, `as_of`, snapshots, and Approval files must be regenerated and verified together.
